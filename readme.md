# 💄 AC Cosmetología – Página Web

Sitio web orientado a la presentación de servicios y productos de una estética. Su objetivo principal es brindar información clara a los clientes y servir como base para futuras funcionalidades de gestión.

---

## 🎯 Objetivo

Mostrar de forma simple y profesional:

* Servicios disponibles
* Productos ofrecidos
* Información de contacto

Y a futuro evolucionar hacia un sistema completo de gestión.

---

## 🚀 Funcionalidades actuales

* 🧾 **Catálogo de servicios**
* 🧴 **Listado de productos**
* 📱 **Diseño responsive**
* 📍 **Información de contacto**
* 💬 **Canales de comunicación (WhatsApp / redes)**

---

## 🔮 Evolución planificada

Este proyecto está diseñado para crecer progresivamente hacia:

* 📅 Sistema de turnos online
* 👥 Gestión de clientes
* 🧴 Control de stock
* 🔐 Sistema de usuarios (admin / empleadas)
* 📊 Panel de administración

---

## 🧱 Estructura del proyecto

```bash id="0jz8v9"
/ac_cosmetologia
│
├── /static        # CSS, JS, imágenes
├── /templates     # Vistas HTML
├── main.py        # Punto de entrada (si aplica backend)
└── ...
```

---

## ⚙️ Tecnologías utilizadas

* HTML
* CSS
* JavaScript
* Python (base para futuras funcionalidades dinámicas)

---

## 🧪 Estado del proyecto

🟢 Versión inicial – Página informativa activa
🟡 En desarrollo continuo

---

## 📦 Instalación (modo desarrollo)

```bash id="9zdb3q"
git clone https://github.com/fernandojyaiy-art/ac_cosmetologia.git
cd ac_cosmetologia
```

(Si el proyecto incluye backend:)

```bash id="4s9g0t"
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py
```
